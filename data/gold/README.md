# Gold test set (10 SBCs)

The gold set is teacher labels plus human-verified corrections. It's the test set for
every model in Phase 2+, so it must never be used for training. When the dataset is
scaled up, **every plan from these 10 brands is excluded from training** (brands like
Oscar share one template across many issuer IDs).

## Files

- `review/<plan_id>.md`: review sheets, generated by `src/review_sheet.py`
- `corrections.json`: every proposed change, with a reason and a status
- `labels/<plan_id>.json`: the gold labels, built by `src/build_gold.py` with
  `accepted` corrections applied

## How to review one document (~10 min)

1. Open the PDF (`data/raw/sbc_pdfs/<plan_id>.pdf`) next to `review/<plan_id>.md`.
2. Check **deductible** and **out-of-pocket limit** (top of the sheet).
3. Check every row marked ⚠️, plus **5 unflagged rows** of your choice. The automatic
   checks only catch some kinds of error.
4. Check the **drug tiers** (names, order, prices) and skim the two lists.
5. For anything wrong, add an entry to `corrections.json`; for proposed entries
   you agree with, set `"status": "accepted"`.
6. Run `uv run python src/build_gold.py`, then tick the document off below.

## First-pass findings (Claude, from the Markdown, not yet confirmed against the PDFs)

19 rows flagged. 13 are false alarms: sub-row layouts, reimbursement-style prices
("All charges less $35 plan payment"), and multi-tier column headers. That leaves
**4 clear errors** and **2 guideline ambiguities**:

| Plan | Field | Teacher | Proposed | Status |
|---|---|---|---|---|
| 11718TX | hospital_surgeon_fee (in) | prices null, note "No charge" | $0 / 0% | proposed |
| 23552TN | diagnostic_test (in) | prices null, all in note | $100 copay (x-ray), lab in note | proposed |
| 23552TN | mental_health_outpatient (in) | prices null, all in note | $15 copay, rest in note | proposed |
| 23552TN | urgent_care (out) | covered, from limitations text | not covered (price column) | proposed |
| 18350HI | emergency_room (in/out) | $60 copay **and** 25% coins | $60 copay, 25% facility in note | accepted (v1.2) |
| 13262AR | mental_health_outpatient (in) | $20 copay **and** 50% coins | 50% coins, $20 copay in note | accepted (v1.2) |

**Resolved by guideline v1.2:** `copay` and `coinsurance_pct` are both filled only when one
charge combines them ("$250 copay then 20%"). When a service has different parts, the first
listed part goes in the structured fields and the rest in `note`. Prices come only from the
price columns, never from the limitations column. The 4 remaining "proposed" rows need
confirming against the PDFs.
